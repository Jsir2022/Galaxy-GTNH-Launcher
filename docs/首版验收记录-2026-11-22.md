## r4 首次安装修正

上一次 Windows 全量下载在创建 LWJGL 库子目录时失败。r4 在联网工作线程启动前串行创建父目录。对传输超时、暂时断线和指定 HTTP 错误单文件最多尝试三次，继续使用校验后的原子写入。Windows x64 清单去掉 26 个 ARM64 和 x86 LWJGL 附件，减少约 15 MB 下载。r4 Linux 便携包复验安装路径通过。r4 Windows 包在 Wine 中从空目录实际下载并解压官方包，安装 244 个模组。后续复跑从同一目录继续下载安装库和资源，未手工补入下载缓存。最终已保存 509 个正式命名的资源文件。Wine 中资源 27fcacc68bb77f01b23ea9c9d36d9018f8509cdf 传输超时，安装入口退出码为 1。本机 Linux 对同一地址下载成功并得到预期 SHA-1。Windows 原生全量联网安装及正版进服仍待验收。

## r5 下载源选择

发行版先通过 Microsoft 登录及 Minecraft 服务权益校验，再下载游戏和整合包。在窗口中可手动选择 Mojang 官方源或 BMCLAPI 国内社区镜像。默认官方并记住玩家选择。已有安装目录时，玩家点击「启动游戏」后才开始授权与安装流程，以便先切换下载源。

Linux 发行包窗口实测能切换并保存两个选项。两条线路分别通过开发用安装探针，在复用其余已校验缓存的安装副本中重新下载客户端 JAR、Mojang 游戏库、资源索引和一个资源对象。两次均完成预检，文件与固定摘要一致。Windows x64 交叉编译及包 CRC 校验通过。真实微软授权和实际进服继续等待 AppID 接入审核。

单次样本以 curl 对测试进程禁用显式代理后测得。相同客户端 JAR 从官方源下载用时 2.05 秒，BMCLAPI 用时 1.10 秒。相同资源对象的用时分别为 2.49 秒和 1.65 秒。两组文件的 SHA-1 分别一致。
