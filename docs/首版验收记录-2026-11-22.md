# GTNH 启动器 0.1.0-r2 验收记录

2026-11-22 · 内部测试构建

| 项目 | 证据 |
| --- | --- |
| Linux x86_64 | Qt 6.10.2 / GCC 原生构建成功。便携包清除构建环境的 Qt 路径后，在 Xvfb 中创建启动器窗口。r2 在本机 Wayland 会话中打开，补齐窗口装饰插件。 |
| 从空目录首次安装 | 在含中文和空格的目录通过便携包实际下载官方 747,848,389 字节客户端档案并验证 SHA-256，解压后安装了 244 个模组 JAR，含两个 Galaxy 附加模组。Minecraft 资源下载并校验 674 个唯一对象。安装入口输出 `GTNH ready`。 |
| Java 25 | 包内 Temurin 25.0.5.1+2 实际运行。实际运行 RFB/Forge 客户端引导。r1 中原版 Guava 15 抢占 Forge Guava 17，导致 AccessTransformer 抛出 NoSuchMethodError。r2 由后置组件替换同坐标库，复测通过 Forge 引导，直到 Minecraft Main 因刻意留空的会话参数退出。该预检没有使用游戏账号，也没有进入游戏。RFB 次线程未捕获异常可能使 JVM 返回 0，r2 会识别这类异常并报告启动失败。 |
| Windows x64 | MinGW-w64 交叉编译成功。PE 架构、Qt DLL 依赖打包及 ZIP CRC 验证完成，包内附 Windows 版 Java 25。Windows 实机运行待验证。 |
| 指定服务器 | 默认 `gtnh.jsir.tech`。查询 SRV 后通过公网入口发送 Minecraft 状态请求并得到 1.7.10、协议号 5 的响应。现役服务端 `online-mode=true`。该请求未进入登录阶段。 |
| 正版授权 | 未注册随机应用 ID 在真实微软设备授权接口上被拒绝，授权流程未发出用户码，也没有返回游戏会话。有效应用 ID、实际正版授权、完整游戏启动和进服仍待验证。 |

Windows 测试包和 Linux 测试包均预设目标服务器。当前测试构建未内置微软 Client ID。验收时配置项目自有、获 Minecraft API 权限的公开应用 ID，并由测试玩家在微软网页授权。应用 ID 为构建输入，账户凭据不进入 Git。
